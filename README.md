BillKeeper: A Household Bill Tracker

Tagline: Keep Bills in Line, Pay Right on Time.

Project Description
BillKeeper is a simple household bill tracking web application that helps families organize and monitor their household bills, payment status, and due dates.

Community Problem
Community: Our Household / Family

Who has the problem: Parents or family members responsible for paying household bills.

Current method: They rely on memory to remember bill due dates and track payments.

Problem Statement:

In our household, parents and family members responsible for paying bills struggle to remember due dates and monitor unpaid bills because they rely on memory. A web page where they can manage household bills and track their payment status would help.

Functional Requirement (FR-01)

Authorized household members can add, view, edit, and archive household bills, including their category, amount, due date, and payment status.

Main Features
- Add, view, and edit household bills
- Delete bills with PIN protection and confirmation
- Archive bills and view archived records
- Track Paid and Unpaid bills
- View upcoming and overdue bills
- Receive in-app notifications and bill reminders
- Mark notifications as read or unread
- Add an optional bill provider
- Protect bill management actions with a household PIN
- View household bill summaries on the dashboard

Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

Data Storage
BillKeeper uses browser Local Storage to save bill records and notification information. Data stays on the same browser and device and is not synchronized across devices.
