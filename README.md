
# BillKeeper - A Household Bill Tracker

Keep Bills in Line, Pay Right on Time.

BillKeeper is a simple household bill tracker that helps
family members record household bills, monitor due dates,
and check payment statuses.

## Main Features

- Add and view household bills
- Edit bill information
- Track paid and unpaid bills
- Display due date reminders
- Archive old bills

## Technology

- HTML
- CSS
- JavaScript
- localStorage

## Data Storage

Bill records are saved in the browser using localStorage.
